# Weather App

## Description
A responsive Weather Application built using HTML, CSS, and JavaScript. It fetches real-time weather data using a Weather API and displays temperature, humidity, wind speed, and weather conditions.

## Features
- Search weather by city name
- Real-time weather information
- Temperature display
- Humidity display
- Wind speed display
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Weather API

## Project Structure
weather/
├── index.html
├── style.css
└── script.js

## How to Run
1. Download the project files.
2. Open index.html in your browser.
3. Search for any city to view weather details.

## Learning Outcomes
- API Integration
- JavaScript DOM Manipulation
- Async/Await
- Responsive Design
